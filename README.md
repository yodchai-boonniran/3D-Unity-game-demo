### 📝 Game Overview
A 3D action game developed using **Unity**, featuring third-person gameplay inspired by action RPGs like Genshin Impact. Players can explore the environment, rotate the camera using the mouse, and engage in combat using punches, kicks, and collected weapons.

### 🎯 Features
- **3D Third-Person Gameplay:** WASD movement with mouse-controlled camera rotation.
- **Combat System:** Attack enemies using punches, kicks, and collected weapons.
- **Coin Collection:** Collect coins to increase the player's score.
- **Score System:** Displays the current score in the top-left corner and ends the game when the target score is reached.
- **High Score:** Displays the high score at the end of the game.
- **Audio System:** Includes sound effects (SFX) and background music (BGM).

### 🛠️ Technologies
- **Game Engine:** Unity
- **Programming Language:** C#
